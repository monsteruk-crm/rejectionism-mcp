# Project context

Rejectionism MCP currently provides a minimal stateless MCP endpoint using Next.js 15 App Router and `mcp-handler` 2. Product workflows beyond the bootstrap tools have not been defined.

## Entry points and ownership

| Area | Source | Responsibility |
| --- | --- | --- |
| MCP | [route.ts](../app/mcp/route.ts) | GET/POST `/mcp`, tool registration, validation, annotations, responses |
| Database runtime | [prisma.ts](../lib/prisma.ts) | Lazy process-level Prisma client using `PrismaPg` and `DATABASE_URL` |
| Database schema | [schema.prisma](../prisma/schema.prisma) | PostgreSQL schema; current example `User` model |
| Prisma CLI | [prisma7.config.ts](../prisma7.config.ts) | Schema/migration paths and CLI database URL |
| Migrations | [initial SQL](../prisma/migrations/20260905134459_init/migration.sql) | Initial `User` table and email uniqueness constraint |
| Protocol smoke client | [test-client.mjs](../scripts/test-client.mjs) | Connect, list tools, call echo and database diagnostic |
| Commands/dependencies | [package.json](../package.json) | pnpm scripts and version requirements |

`check_database` follows MCP request → route handler → Prisma singleton → PostgreSQL `SELECT 1` → sanitized tool result. It never reads the example `User` table. Stateless MCP transport does not mean the database or process-level connection pool is stateless.

Generated client code lives under `app/generated/prisma`, is ignored by Git, and is regenerated by `postinstall: prisma generate`. The repository uses Prisma CLI/client 7.10.0 and the PostgreSQL adapter. Installed Composer skills do not establish a Composer runtime architecture.

No application authorization layer is implemented in the MCP route. The existing diagnostic takes no SQL or connection arguments and returns no records or credentials. Define access-control requirements before adding tools that expose protected data or perform writes.

See the [tool contract](contracts/mcp-tools.md) and [runbook](runbooks/local-development.md) before changing these surfaces.
